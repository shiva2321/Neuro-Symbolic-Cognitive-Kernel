NSCK Architecture Documentation
System Overview
The Neuro-Symbolic Cognitive Kit (NSCK) is a hybrid cognitive architecture that combines three complementary paradigms:

Spiking Neural Networks (SNNs) - Neuromorphic, energy-efficient visual processing
Vector Symbolic Architectures (VSA) - High-dimensional holographic memory and reasoning
Active Inference - Bayesian decision-making with free energy minimization
NSCK implements a teacher-student learning paradigm where heuristic teachers guide SNN students through disagreement-based intervention, enabling multi-task reinforcement learning across multiple game environments (Snake, Pong).

Mathematical Foundations
1. Leaky Integrate-and-Fire (LIF) Neuron Model
The core computational unit of the SNN is the LIF neuron with the following discrete-time dynamics:

Membrane Potential Update
U[t] = β * U[t-1] + I[t]
Where:

U[t] = Membrane potential at time t
β = Decay factor (leak constant, default 0.5)
I[t] = Input current from synaptic weights
Spike Generation
S[t] = H(U[t] - θ)

where H(x) = {
 1  if x ≥ 0
 0  if x < 0
}
Where:

S[t] = Binary spike output at time t
θ = Firing threshold (default 0.5)
H() = Heaviside step function
Reset Mechanism
U[t] = U[t] - θ * S[t]
After spiking, the membrane potential is reduced by the threshold value.

2. Surrogate Gradient Method
The Heaviside function is non-differentiable, preventing standard backpropagation. NSCK uses the Fast Sigmoid Surrogate Gradient:

Forward Pass
∂S/∂U = H(U - θ)   (standard Heaviside)
Backward Pass (Surrogate)
∂S/∂U ≈ σ'(U) = k * σ(k*U) * (1 - σ(k*U))

where σ(x) = 1 / (1 + e^(-x))
Where:

k = Slope parameter (default 25)
Higher k = steeper approximation of step function
This allows gradients to flow through the network during backpropagation through time (BPTT).

3. Multi-Task Learning with Late Fusion
The TaskAwareSNN implements a late fusion architecture where task context is injected after shared feature extraction:

Shared Feature Extraction
F_shared = LIF(Conv2D(LIF(Conv2D(X))))
Where X is the 4-frame temporal stack: [Batch, 4, 10, 10]

Late Fusion with Task Context
F_flat = Flatten(F_shared)                    // [Batch, 288]
T_id = TaskID                                 // Scalar: 0 (Pong) or 1 (Snake)
F_fused = Concat([F_flat, T_id])             // [Batch, 289]
F_latent = LIF(FC(F_fused))                  // [Batch, 64]
Task-Specific Output Heads
If TaskID == 1:  // Snake
   Y = LIF(FC_snake(F_latent))              // [Batch, 4]
   
If TaskID == 0:  // Pong
   Y = LIF(FC_pong(F_latent))               // [Batch, 2]
Rate Coding Output
R = Σ(S[t] for t in [0, T])                  // Sum spikes over T=8 timesteps
P = Softmax(R)                                // Convert to action probabilities
4. Teacher-Student Disagreement Gate
The disagreement gate determines when the teacher intervenes to correct the student:

Decision Logic
action_student = argmax(Softmax(R_student))
action_teacher = Oracle(state)

if action_student == action_teacher:
   // Agreement: Student is correct
   action_final = action_student
   loss = 0
   train = False
else:
   // Disagreement: Intervention required
   action_final = action_teacher
   loss = CrossEntropy(R_student, action_teacher)
   train = True
   BackwardPass()
   OptimStep()
Cross-Entropy Loss
L = -Σ(y_true[i] * log(p_pred[i]))

where:
   y_true = One-hot encoding of teacher action
   p_pred = Softmax(R_student)
5. Stratified Replay Buffer
The replay buffer maintains four stratified quadrants to ensure balanced sampling:

Buffer Structure:
┌─────────────────┬─────────────────┐
│  Snake-Agree    │  Snake-Disagree │
│  Deque(2500)    │  Deque(2500)    │
├─────────────────┼─────────────────┤
│  Pong-Agree     │  Pong-Disagree  │
│  Deque(2500)    │  Deque(2500)    │
└─────────────────┴─────────────────┘
Sampling Strategy
batch_per_quadrant = BATCH_SIZE // 4        // 32 // 4 = 8

For each quadrant in [SnakeAgree, SnakeDisagree, PongAgree, PongDisagree]:
   samples = Random_Sample(buffer[quadrant], min(8, len(buffer[quadrant])))
   batch.extend(samples)

Shuffle(batch)
This ensures:

Task Balance: Equal representation from Snake and Pong
Intervention Balance: Equal mix of correct (agree) and incorrect (disagree) predictions
Catastrophic Forgetting Prevention: Rehearsal of old experiences during sleep
6. Sleep Consolidation
NSCK implements a sleep cycle for memory consolidation triggered by:

Task Switch: Context change from Snake ↔ Pong
Periodic Interval: Every 1000 steps
Sleep Algorithm
For epoch in [1, SLEEP_EPOCHS]:
   // Sample Snake experiences
   batch_snake = Stratified_Sample(buffer, game="snake", size=BATCH_SIZE//2)
   loss_snake = Train_Batch(model, batch_snake, task_id=1)
   
   // Sample Pong experiences
   batch_pong = Stratified_Sample(buffer, game="pong", size=BATCH_SIZE//2)
   loss_pong = Train_Batch(model, batch_pong, task_id=0)
   
   total_loss += loss_snake + loss_pong
This mimics biological memory consolidation during sleep phases.

Vector Symbolic Architecture (VSA)
High-Dimensional Binary Hypervectors
NSCK implements VSA using 10,240-dimensional binary vectors (1.25KB per vector).

Random Hypervector Generation
V = Random({0,1}^D)    where D = 10,240
Each bit is sampled i.i.d. from Bernoulli(0.5).

VSA Operations
1. Binding (XOR)
Binding creates a new vector that encodes the association between two concepts:

C = A ⊕ B

Properties:
• C is dissimilar to both A and B
• Approximate inverse: C ⊕ B ≈ A
• Commutative: A ⊕ B = B ⊕ A
• Associative: (A ⊕ B) ⊕ C = A ⊕ (B ⊕ C)
2. Bundling (Majority Vote)
Bundling creates a superposition vector similar to both inputs:

For two vectors A and B:
   C[i] = {
       A[i]           if A[i] == B[i]
       Random({0,1})  if A[i] ≠ B[i]
   }

For N vectors:
   C[i] = Majority({V₁[i], V₂[i], ..., Vₙ[i]})
Properties:

Sim(C, A) ≈ Sim(C, B) (C is similar to both parents)
Noise-resistant: Robust to bit flips
3. Similarity (Normalized Hamming Distance)
HammingDistance(A, B) = Σ(A[i] ⊕ B[i])

Similarity(A, B) = 1 - (HammingDistance(A, B) / D)

Range: [0, 1]
• 0 = Completely dissimilar (orthogonal)
• 1 = Identical vectors
• ~0.5 = Random unrelated vectors
Codebook Structure
The system maintains atomic concept vectors:

Codebook = {
   # Directions
   "NORTH":  HyperVector(seed=1),
   "SOUTH":  HyperVector(seed=2),
   "EAST":   HyperVector(seed=3),
   "WEST":   HyperVector(seed=4),
   
   # Perceptions
   "APPLE":      HyperVector(seed=5),
   "WALL":       HyperVector(seed=6),
   "EMPTY":      HyperVector(seed=7),
   "SNAKE_BODY": HyperVector(seed=8),
   
   # Intents
   "INTENT_PLAY_SNAKE": HyperVector(seed=9),
   "INTENT_UNKNOWN":    HyperVector(seed=10)
}
Compositional Representations
VSA enables compositional reasoning through binding and bundling:

# Rule: "If APPLE is NORTH, move NORTH"
Rule = (APPLE ⊕ NORTH) + (ACTION ⊕ MOVE_NORTH)

# Query: "What to do when APPLE is NORTH?"
Query = APPLE ⊕ NORTH
Response = Rule ⊕ Query → ACTION ⊕ MOVE_NORTH
Action = Response ⊕ ACTION → MOVE_NORTH
Active Inference Framework
Generative Model
Active Inference uses a generative model with:

States (Hidden)
S = {Apple_N, Apple_S, Apple_E, Apple_W}
Observations
O = {Apple, Wall, Empty}
From SNN visual classification.

Actions
A = {Move_N, Move_S, Move_E, Move_W}
Model Matrices
A-Matrix (Likelihood): P(O | S)
Maps hidden states to observations:

A[o, s] = P(observation=o | state=s)
B-Matrix (Transition): P(S_t+1 | S_t, A)
State transition dynamics under actions:

B[s', s, a] = P(state_next=s' | state=s, action=a)
C-Matrix (Preferences)
Prior preferences over observations:

C[o] = log P_preferred(o)

Example:
C[Apple] = +5.0    // Strong preference for eating apple
C[Wall] = -5.0     // Strong avoidance of collision
C[Empty] = 0.0     // Neutral about empty space
Expected Free Energy
The agent minimizes Expected Free Energy (EFE) for policy selection:

G(π) = E_Q(o,s|π)[log Q(s|π) - log P(o, s)]

    = E_Q(o,s|π)[log Q(s|π) - log P(o|s) - log P(s)]
    
    = Epistemic_Value + Pragmatic_Value
Where:

Epistemic Value: Information gain (exploration)
Pragmatic Value: Expected reward (exploitation)
Policy Selection (Softmax)
P(π) ∝ exp(-γ * G(π))

where γ = precision parameter (inverse temperature)
VSA-Modulated Precision
VSA similarity scores modulate inference precision:

Precision(observation) = Similarity(obs_vsa, codebook)

High Similarity (>0.8):   High precision → Trust observation
Low Similarity (<0.5):    Low precision → Rely on prior
This implements neuro-symbolic uncertainty where symbolic confidence modulates neural decision-making.

Architectural Advantages
1. Multi-Task Learning
Shared Visual Cortex: Common feature extraction across tasks
Late Fusion: Task-specific processing after shared features
Minimal Forgetting: Stratified replay prevents catastrophic forgetting
2. Teacher-Student Paradigm
Fast Bootstrap: Heuristics provide initial guidance
Intervention Efficiency: Only train on mistakes
Graceful Degradation: Student takes over as it learns

Spike-Based: Native compatibility with neuromorphic hardware
