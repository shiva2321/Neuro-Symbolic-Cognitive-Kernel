# NSCK V5 Changelog (March 2026)

## [V5.0.0] - Societal Knowledge World

### Added
- **SocietalKnowledgeWorld**: A new hierarchical memory substrate where hypervectors behave as autonomous citizens.
- **Hierarchical Domain Model**: Recursive nesting of knowledge into Towns, Cities, States, Countries, and Continents.
- **Spectral Renormalization Group**: Automated coarse-graining of large knowledge graphs using spectral eigendecomposition.
- **Hodge Laplacians (L0, L1, L2)**: Higher-order topological analysis for triadic closure and latent flow detection.
- **TDA Persistent Homology**: Real-time monitoring of semantic health via Betti numbers ($\beta_0, \beta_1$).
- **Percolation Monitor**: Autonomous domain emergence based on cluster density and phase transitions.
- **V5 Web Dashboard**: A premium glassmorphism UI with a custom physics-based Galaxy View visualizer.
- **LivingHyperVector**: Active state tracking for concepts (energy, stability, social valence).

### Changed
- **SocietalHNSW**: Upgraded the hierarchical HNSW index to support multiscale societal layers.
- **SemanticMemory**: Integrated the Societal Context Router for hierarchical reasoning.
- **CognitiveEngine**: Added the `SOCIETAL` coalition for global workspace broadcasts.

### Fixed
- **Hodge Laplacian Stub**: Fully implemented L2 triadic closure calculation.
- **Spectral Embedding**: Improved stability of normalized Laplacian eigendecomposition.
- **Zipf Validation**: Corrected MLE estimator for power-law alpha health checks.

### Documentation
