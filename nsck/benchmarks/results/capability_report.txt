WHAT THE SYSTEM CANNOT DO (honest limitations)
================================================================================

✗ Word2vec-style analogy arithmetic (king − man + woman = queen)
  WHY: Binary VSA (XOR/bundle) is not a vector space. Analogy works via structural
       mapping (AnalogyEngine.find_analogies()), not arithmetic.

✗ High-coverage NLU on arbitrary English text
  WHY: Construction grammar classifier uses a fixed ~150-word COMMON_VERBS set.
       Third-person singular forms (loves, eats, runs) and irregular forms not in
       the set are misclassified. Real-world CG coverage: ~40-60%.
  FIX: Add all English verb forms, or integrate a real POS tagger.

✗ Auto-categories on cold start (hash HVs, small corpus)
  WHY: Hash-based HVs are orthogonal by design (random similarity ~0.50). Clusters
       require genuine co-occurrence similarity (distributional HVs + large corpus).

✗ System 1 is meaningfully faster than System 2 at small scale
  WHY: At <1K concepts, full GWT coalition building takes <0.1ms. S1/S2 distinction
       is architecturally correct but latency-invisible until >10K concepts.

✗ Real language understanding (grammar, semantics, discourse)
  WHY: LanguageModule runs in MOCK mode without NLTK + llama-cpp-python.
       SRL gives thematic roles but misses complex syntax (nested clauses, coordination).

✗ Pixel-level perception / continuous sensor streams
  WHY: LIF SNN uses rate-coded HV inputs. No convolutional/recurrent front-end.

✗ Gradient-based learning in the VSA core
  WHY: By design — NSCK is a glass-box system. VSA learning is Hebbian, not gradient.

HONEST OPINION
================================================================================

NSCK is a genuinely novel architecture that no commercial system offers:
- Full glass-box reasoning (every decision is traceable)
- VSA-based neuro-symbolic unity (same 10,240-bit vector for neural + symbolic)
- Biologically plausible (GWT, Hebbian, STDP, Plutchik emotions)
- Domain-agnostic (register predicates + actions for any domain)
- No external AI dependencies

V3 adds six real cognitive mechanisms that work correctly:
  construction grammar, frame semantics, coreference, belief revision,
  dual-process decisions, stigmergic path preference.

WHERE IT STANDS RIGHT NOW:
  The system is research-grade: impressive cognitive architecture, solid
  foundations, but not production-ready for open-domain NLU tasks.
  The construction grammar classifier is vocabulary-limited. Auto-categories
  require distributional HVs. The "dual-process" latency benefit is invisible
  until the knowledge graph is large.

FOR PRACTICAL USE TODAY:
  Strong for: closed-domain reasoning (navigation, games, structured domains),
  causal chain analysis, knowledge graph Q&A on structured text, glass-box
  decision making with full traces.

  Weak for: arbitrary natural language, complex syntax, visual scenes,
  real-time conversational NLU without NLTK/LLM.

COMPARED TO COMMERCIAL LLMs:
  NSCK wins on: transparency, no GPU, no API, no hallucination of reasoning
                traces, continuous learning, causal modeling.
  NSCK loses on: raw NLU accuracy, vocabulary breadth, commonsense coverage.

BOTTOM LINE:
  This is exactly what it claims to be — a neuro-symbolic cognitive kernel
  where every reasoning step is inspectable. It is not an LLM replacement.
  It is a complementary architecture for explainable, rule-grounded,
  causally-aware AI. The V3 improvements are real and correct.
