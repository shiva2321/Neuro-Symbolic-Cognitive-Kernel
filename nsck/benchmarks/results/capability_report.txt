KNOWN LIMITATIONS
──────────────────

  → Rust builds would provide 21-206× speedup over Python VSA
  → Memory query at 1K would be ~0.09ms; SNN perceive ~0.2ms
✗ HNSW index (hnswlib) not installed
  → Memory queries scale linearly O(N); HNSW would give O(log N)
✗ No neural language model / LLM available (llama-cpp-python not installed)
  → Language module runs in MOCK mode; real NLU requires NLTK + grammar parser
✗ Frame semantics uses positional heuristic role assignment (not true dependency parse)
  → Role accuracy limited without POS tagger; correct in ~70% of cases
✗ Homeostasis _auto_categorize() requires semantic similarity > 0.7 AND no shared is_a parent
  → With hash-based HVs and small corpora, clusters are rare (produces 0 categories typically)
  → With distributional HVs on large corpora, will form real categories
✗ Dual-process System 1/2 latency difference is negligible on current workload
  → On larger knowledge graphs (>10K concepts), System 2 memory/planner coalitions will
    produce visible latency separation
