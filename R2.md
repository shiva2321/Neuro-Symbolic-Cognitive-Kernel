# Engineering Specifications for High-Fidelity Cognitive Architectures
## Bridging the Gap Between Neural Dynamics and Symbolic Reasoning

### 1. Algorithmic Specification: From Abstract Modules to Energy-Based Execution Dynamics
The transition from a theoretical blueprint of a cognitive architecture to a functional engineering specification requires a fundamental shift in how computation is defined. The critique of "algorithmic under-specification" identifies a pervasive failure in current blueprints: the tendency to describe cognitive functions as "black boxes" (e.g., "Reasoning Module," "Memory Store") without defining the underlying dynamical laws that govern their operation. In a robust, neuro-symbolic system, execution cannot be defined merely as procedural code; it must be specified as the trajectory of a dynamical system relaxing toward an energy minimum on a complex, high-dimensional landscape. This section provides the rigorous engineering specifications for these mechanisms, integrating Modern Hopfield Networks, Constraint Satisfaction Neural Networks, and Hypergraph dynamics to resolve execution complexity.

#### 1.1 The Computational Substrate: Modern Hopfield Networks (MHNs) and Dense Associative Memory
To address the execution complexity of memory retrieval and pattern completion, we specify the Modern Hopfield Network (MHN), also referred to as Dense Associative Memory, as the foundational computational unit. Unlike classical Hopfield networks, which rely on binary neurons and suffer from limited linear storage capacity ($0.14N$), MHNs utilize continuous state variables and highly non-linear interaction functions (typically polynomial or exponential) to achieve exponential storage capacity ($2^{N/2}$) and one-shot retrieval capabilities.

##### 1.1.1 Energy Function Specification and Logical Mapping
The core "algorithm" for memory execution is defined not by a sequence of logical steps, but by the descent on a global energy landscape $E(x)$. The engineering specification requires constructing this landscape such that the attractors (local minima) correspond to valid memories or consistent logical states.

For a state vector $x \in R^d$ and a matrix of stored patterns $X=[\xi_1, \dots, \xi_M]$, the energy function for a continuous MHN is formally specified as:

$$E(x) = -\frac{1}{\beta} \text{lse}(\beta X^T x) + \frac{1}{2} x^T x = -\frac{1}{\beta} \ln \left( \sum_{i=1}^{M} \exp(\beta x^T \xi_i) \right) + \frac{1}{2} ||x||^2$$

where $\beta$ is the inverse temperature parameter. This energy function ensures that the update rule for the state $x$ converges to a fixed point that is a convex combination of the stored patterns, weighted by their similarity to the current state.

**Integration of Logical Constraints:** To resolve the critique regarding the lack of symbolic reasoning capabilities, we extend this substrate to support Neuro-Symbolic Integration. The energy landscape must reflect not just similarity, but logical satisfiability. We define the mapping of logical constraints (e.g., k-SAT clauses) directly into the energy function using the Major 1,3 Satisfiability logic or similar high-order formulations. A logical clause $C_j$ is mapped to an energy penalty term $P_j(x)$. For example, a clause $(x_1 \lor \neg x_2 \lor x_3)$ contributes energy to the system if violated.

The total energy function becomes:
$$E_{total}(x) = E_{memory}(x) + \sum_{j} \lambda_j w_j P_j(x)$$

where $\lambda$ governs the strength of logical constraints versus memory attraction. This formulation transforms "reasoning" into a physical process: the system relaxes into a state that simultaneously satisfies stored memories (priors) and logical rules (constraints), effectively performing Maximum Satisfiability (MAX-SAT) via gradient descent.

##### 1.1.2 Dynamics and Attention Mechanisms
The execution dynamics—the "algorithm" itself—are specified by the update rule derived from minimizing this energy. For the softmax-based energy function, the update rule is:

$$x_{t+1} = \text{softmax}(\beta X^T x_t)X$$

Crucially, this update rule is mathematically equivalent to the self-attention mechanism found in Transformer architectures. This equivalence provides a critical engineering bridge: it allows us to utilize the powerful, parallelizable hardware optimizations developed for Transformers (e.g., matrix multiplication units) while retaining the theoretical guarantees of associative memory and attractor dynamics. This resolves the ambiguity of how "attention" and "memory" interact—they are manifestations of the same underlying energy minimization process.

#### 1.2 Constraint Satisfaction Neural Networks (CSNN): Solving Execution Complexity
While MHNs handle associative retrieval, complex reasoning requires solving Constraint Satisfaction Problems (CSPs). The critique notes that purely symbolic solvers are brittle, while pure neural networks lack precision. We specify the use of Constraint Satisfaction Neural Networks (CSNN) as the dedicated engine for solving CSPs within the architecture.

##### 1.2 Architecture and relaxation
The CSNN is defined as a graph where nodes represent variables (hypotheses) and edges represent constraints.
*   **Nodes ($U_i$):** Represent the probability or confidence of a specific hypothesis (e.g., "Object A is a Chair").
*   **Weights ($W_{ij}$):** Encode the constraints. Positive weights represent consistency (support), while negative weights represent inconsistency (conflict).

The "execution" is the relaxation of the network state over time $t$, governed by the differential equation:

$$\tau \frac{du_i}{dt} = -u_i + \text{Input}_i + \sum_{j} W_{ij} f(u_j)$$

This dynamic allows the system to settle into a global solution that maximizes the satisfaction of constraints. Unlike brittle symbolic solvers that fail on inconsistent data, CSNNs find the "best fit" solution, exhibiting robust graceful degradation. This is essential for dealing with the noisy, often contradictory data found in real-world environments.

**Global Constraints via Inhibitory Pools:** To enforce global constraints (e.g., "Only one object can be at location (x,y)"), we specify the use of Winner-Take-All (WTA) inhibitory pools. A set of neurons competing for a single logical slot mutually inhibit each other, ensuring that as one hypothesis gains strength, it suppresses alternatives. This implements the logical XOR constraint via neural lateral inhibition.

#### 1.3 Hypergraph Neural Networks (HGNN): capturing High-Order Correlations
Standard graph networks model pairwise relationships. However, cognitive concepts often involve high-order correlations (e.g., the relationship between a subject, object, and context). To address the "under-specification" of complex relational reasoning, we mandate the use of Hypergraph Neural Networks (HGNN).

**Specification:**
*   **Hyperedge Convolution:** Instead of aggregating messages from direct neighbors, nodes aggregate information from all peers connected by a hyperedge $e$.
    $$x_i^{(l+1)} = \sigma \left( \sum_{e \in E_i} \sum_{j \in e} W_e x_j^{(l)} \right)$$
*   **Generative Structure Learning:** The hypergraph structure itself is not static. We specify a Generative Hypergraph mechanism where the system dynamically infers hyperedges based on node similarity or temporal co-occurrence, effectively "learning" new high-order relations on the fly. This provides a mechanism for concept formation—grouping disparate entities into a single, addressable hyperedge.

#### 1.4 Hierarchical Predictive Coding (PC): The Error-Propagation Engine
To handle perceptual execution complexity, we replace standard feedforward networks with Hierarchical Predictive Coding (PC). This inverts the flow of information: higher levels predict the activity of lower levels, and only the prediction error propagates upward.

##### 1.4.1 Error Dynamics Specification
The execution logic for a PC layer $l$ is defined by two coupled differential equations representing the update of value nodes $x_l$ and error nodes $e_l$. The objective is to minimize the local Free Energy $F$:

$$F = \sum_l \frac{1}{2} ||e_l||^2 = \sum_l \frac{1}{2} ||x_l - f(W_{l+1} x_{l+1})||^2$$

The dynamics are:
*   **State Update:** $\frac{dx_l}{dt} = e_l - W_l^T e_{l-1} f'(x_l)$
*   **Error Calculation:** $e_l = x_l - f(W_{l+1} x_{l+1})$

This specification ensures that the system is constantly active, attempting to "explain away" sensory data. High prediction error ($e_l$) serves as an intrinsic signal for salience, driving learning and attention to unexplained phenomena.

### 2. Coordination Overhead and Signal Interference: The Orthogonality Imperative
The second critical gap is "Coordination overhead/signal interference." In a modular cognitive architecture, diverse subsystems (Vision, Language, Motor, Planning) must exchange high-fidelity information without corrupting each other's signals. The "blueprint" assumption of ideal communication channels is physically and computationally invalid. To resolve this, we specify a communication protocol based on High-Dimensional Geometry and Active Gating.

#### 2.1 Vector Symbolic Architectures (VSA/HDC): The Encoding Standard
To mitigate signal interference, we specify Vector Symbolic Architectures (VSA), also known as Hyperdimensional Computing (HDC), as the universal data interchange format. The core engineering principle is Quasi-Orthogonality: in high-dimensional space ($D \ge 10,000$), any two randomly generated vectors are approximately orthogonal. This property allows the system to superimpose multiple signals into a single channel without destructive interference.

##### 2.1.1 Algebra of Concepts
The VSA specification requires the implementation of three fundamental operations that form an algebra over the vector space:
1.  **Superposition (Addition +):** Represents sets or collections. $S = A + B$. Crucially, $S$ remains similar to both $A$ and $B$, allowing for fuzzy retrieval.
2.  **Binding (Multiplication $\otimes$):** Represents variable-value assignment or role-filler relationships. $Z = X \otimes Y$. The result $Z$ is dissimilar (orthogonal) to both $X$ and $Y$, protecting the constituents from interference.
3.  **Permutation ($\Pi$):** Encodes sequence or order. $V_{seq} = A + \Pi B + \Pi^2 C$. This is essential for temporal cognition.

**The Unbinding Operation:** Information is retrieved via the inverse operation. For example, to retrieve the value associated with a role:
$$\text{Value} \approx \text{BoundVector} \otimes \text{Role}^{-1}$$

The noise introduced by other superimposed vectors is distributed across the high-dimensional space and effectively vanishes during the readout process (Cleanup Memory). This mathematically guarantees that the system can maintain distinct representations for "Red Apple" and "Green Truck" without confusing them into "Red Truck," solving the Binding Problem inherent in standard neural networks.

##### 2.1.2 Representing Knowledge Graphs in VSA
To bridge the gap between symbolic Knowledge Graphs (KGs) and neural dynamics, we specify the embedding of KGs into VSA hypervectors. Each entity ($h$) and relation ($r$) is assigned a static random hypervector. A triple $(h,r,t)$ is encoded as $h \otimes r \otimes t$ or $h \otimes r + t$ depending on the specific VSA implementation (e.g., HRR, MAP). The entire graph is the superposition of these triple vectors:
$$G = \sum_i (h_i \otimes r_i \otimes t_i)$$
This allows the system to perform graph traversal and query operations using simple vector algebra (e.g., "Who is the father of Thor?" becomes $G \otimes \text{Thor} \otimes \text{Father}^{-1} \approx \text{Odin}$). This enables symbolic reasoning at neural speeds without traversing pointer structures.

#### 2.2 Thalamic Gating: The Active Routing Switchboard
While VSA protects signals from crosstalk, efficient coordination requires active routing. Broadcasting every signal to every module is energetically prohibitive and leads to "cognitive clutter." We specify a Thalamic Gating Mechanism modeled on the biological thalamocortical loop to act as the central switchboard.

##### 2.2.1 Gating Dynamics and Basal Ganglia Control
The Thalamus consists of relay nuclei that gate information flow between cortical modules (e.g., from Visual Cortex to Prefrontal Cortex). The default state of these gates is closed (tonic inhibition).
*   **Controller:** The Basal Ganglia (BG) acts as the gatekeeper. It receives context from the cortex and computes the "salience" or "utility" of opening specific communication channels.
*   **Mechanism:** The BG output (Globus Pallidus internal, GPi) provides tonic inhibition to the Thalamus. To open a gate, the Striatum (BG input) inhibits the GPi, causing disinhibition of the target thalamic nucleus.
*   **Update Rule:** The selection of which gate to open is a Reinforcement Learning (RL) problem solved by the BG, typically modeled using Q-learning or Actor-Critic methods, where the "action" is the routing decision.

**Engineering Implication:** This architecture enforces a "speak only when spoken to" protocol. Modules process locally and only broadcast globally when the BG determines that their information is relevant to the current goal. This drastically reduces coordination overhead and energy consumption.

#### 2.3 Homeostatic Plasticity and Synaptic Scaling
To prevent "signal runaway" (epileptic-like over-excitation) or "signal death" (silence) in a highly interconnected system, we must specify mechanisms for signal stability. We incorporate Homeostatic Plasticity, specifically Synaptic Scaling.

**Specification:** Each neuron $i$ maintains a running average of its firing rate $\bar{r}_i$. If $\bar{r}_i$ deviates from a target setpoint $r_{target}$, all afferent synaptic weights $w_{ij}$ are scaled multiplicatively:
$$\tau_{hom} \frac{dw_{ij}}{dt} = \alpha (r_{target} - \bar{r}_i) w_{ij}$$
where $\tau_{hom}$ is a slow time constant (minutes/hours) compared to the fast Hebbian learning ($\tau_{hebb}$).

**Function:** This ensures that neurons remain in their sensitive dynamic range. If a module becomes too active (interference), synaptic scaling automatically gains it down. If it becomes silent (disconnect), scaling gains it up. This provides a self-organizing stability mechanism that requires no central coordinator.

### 3. Fragile System 2 'Thinking Policy': Metacognition and Bounded Rationality
The critique highlights a "Fragile System 2," specifically the lack of robust stopping criteria and bounded search. Cognitive architectures often fall into infinite reasoning loops or use arbitrary heuristics (e.g., "search depth 5"). To engineer a robust System 2, we must formalize Metacognition and Bounded Rationality using thermodynamic and economic principles.

#### 3.1 Stopping Criteria: The Value of Computation (VoC)
We replace ad-hoc stopping rules with a principled Value of Information (VoI) or Value of Computation (VoC) metric. The system should continue "thinking" (simulating future states) only if the expected utility gain of the computation exceeds its cost.

**Engineering Specification 3.1:** Let $U(\alpha)$ be the utility of the current best action $\alpha$. Let $C$ be a computational step (e.g., expanding a search node). Let $\text{Cost}(C)$ be the metabolic or temporal cost of that step. The system executes $C$ if and only if:
$$E[U(\alpha')|C] - U(\alpha) > \text{Cost}(C)$$
where $U(\alpha')$ is the posterior utility after computation.

**Implementation:** This calculation is performed by a Metacognitive Module (functionally mapping to the Anterior Cingulate Cortex, ACC). The ACC monitors the rate of improvement in the solution quality. If the rate of free energy minimization ($dF/dt$) plateaus, the ACC signals "Enough," triggering the transition from deliberation to action. This effectively implements an Anytime Algorithm, where the system can produce a valid (though potentially suboptimal) response at any moment of interruption.

#### 3.2 Neural Algorithmic Reasoning (NAR): Robust System 2
Instead of relying on brittle symbolic solvers (e.g., Prolog engines) that crash on noisy data, we specify Neural Algorithmic Reasoning (NAR). NAR involves training Graph Neural Networks (GNNs) to simulate the execution of classical algorithms (BFS, DFS, Bellman-Ford, Sorting) within a high-dimensional latent space.

**Engineering Specification 3.2:**
*   **Processor:** A single, generalist GNN trained on the CLRS Benchmark. This benchmark contains execution traces of 30+ classical algorithms.
*   **Mechanism:** The GNN learns the step-by-step transition function of the algorithms. $h_{t+1} = \text{GNN}(h_t, \text{graph})$.
*   **Benefit:** Because the algorithm is executed in a continuous latent space, it is differentiable and robust to noise. It can "interpolate" between algorithms or handle fuzzy inputs that would break a discrete solver.
*   **Generalization:** By training on a diverse set of algorithmic tasks, the processor learns a "basis set" of reasoning primitives (e.g., pointer manipulation, value accumulation) that generalize to novel, unseen problems.

This transforms System 2 from a fragile logical inference engine into a robust, learnable dynamical process that mimics algorithmic execution.

#### 3.3 Conflict Monitoring and Gain Modulation
To dynamically allocate System 2 resources, we implement a Conflict Monitoring loop.

**Specification:**
*   **Sensor:** The ACC measures Response Conflict, defined as the simultaneous activation of mutually exclusive plans or high energy variance in the Hopfield network.
    $$\text{Conflict} = \sum_{i \ne j} w_{ij}^{inh} x_i x_j$$
*   **Actuator:** High conflict triggers the release of norepinephrine/dopamine signals to the Prefrontal Cortex (PFC).
*   **Effect:** This neuromodulation increases the gain ($\beta$, inverse temperature) of the neural populations in the PFC.
    $$x_i = \frac{1}{1 + \exp(-\beta(\text{input}_i))}$$
    Increasing $\beta$ sharpens the sigmoid, making the network more decisive and "winner-take-all." This suppresses noise and forces the system to settle into a specific attractor, effectively "focusing attention" to resolve the conflict.

#### 3.4 Metacognitive Architecture Extension
We adopt the Common Model of Cognition (CMC) but extend it with explicit metacognitive loops as seen in architectures like LIDA and CLARION.

**Specification:**
*   **Object Level:** Perception $\rightarrow$ Working Memory $\rightarrow$ Action.
*   **Meta Level:** Monitors the trace of the Object Level. It detects "Cognitive Failure Modes" such as infinite loops, impasses (no valid operators), or low confidence.
*   **Intervention:** The Meta Level does not act on the world; it acts on the parameters of the Object Level. It can, for example, switch the reasoning strategy from "Hill Climbing" to "Random Walk" or initiate a "Goal Management" process to decompose an unsolvable goal.

### 4. Embodiment as a Forcing Function: The Active Inference Loop
The critique correctly identifies that without embodiment, cognitive architectures lack "grounding"—symbols are merely circular definitions. To resolve this, we specify Embodiment not just as the addition of a robot arm, but as the closure of the Active Inference loop. The system acts to minimize the discrepancy between its internal model and sensory reality.

#### 4.1 Minimizing Expected Free Energy (EFE)
In Active Inference, the agent does not maximize a scalar reward; it minimizes Variational Free Energy. Action selection is driven by the minimization of Expected Free Energy (EFE), denoted as $G(\pi)$ for a policy $\pi$.

**Engineering Specification 4.1:** Select policy $\pi^* = \text{argmin}_\pi G(\pi)$, where:
$$G(\pi) \approx \underbrace{D_{KL}[q(s|\pi)||p(s)]}_{\text{Risk (Pragmatic)}} + \underbrace{E_q[H(o|s)]}_{\text{Ambiguity (Epistemic)}}$$

*   **Risk (Pragmatic Value):** The divergence between predicted future states and preferred (prior) states. This drives the agent to fulfill its needs (homeostasis) and goals.
*   **Ambiguity (Epistemic Value):** The expected entropy of observations. Minimizing this drives the agent to explore states that resolve uncertainty about the world (Curiosity).

**The Forcing Function:** This formulation provides a rigorous definition of "grounding." If the agent's internal model is inaccurate (e.g., it believes "I can fly"), the observed sensory consequences of acting on that belief (falling) will generate a massive prediction error (Surprise). To minimize Free Energy, the agent must update its model to align with physical reality. The environment acts as an unyielding adversary that forces the internal model to be veridical.

#### 4.2 Structural Plasticity and Successor Representations
The architecture must adapt its structure to the environment.

**Successor Representation (SR):** To bridge the gap between reactive control and planning, we utilize the Successor Representation. Instead of encoding "place," the Hippocampus/Cortex encodes the "predictive map" of future state occupancies:
$$M(s,s') = E[\sum_{t=0}^{\infty} \gamma^t I(s_t = s') | s_0 = s]$$
This allows the agent to compute values and paths via simple linear algebra ($V = M \cdot R$) rather than expensive tree search, enabling rapid System 1 planning that is still topologically grounded.

**Structural Plasticity:** When the SR fails to predict transitions (e.g., a new wall appears), the massive prediction error triggers Structural Plasticity. We specify a mechanism where high error signals induce the formation of new synapses (generative growth) and the pruning of silent ones. This allows the "Knowledge Graph" of the agent to physically reconfigure itself to match the new environmental topology.

#### 4.3 Addressing Failure Modes
We explicitly address the failure modes of embodied agents:
*   **Tool Hallucination:** In LLMs, agents often "imagine" a tool works. In Active Inference, the attempt to use the tool generates immediate proprioceptive and visual feedback. If this contradicts the prediction (the screw didn't turn), the "Tool Affordance" hypothesis is immediately suppressed by the error signal.
*   **Goal Misinterpretation:** By encoding goals as Prior Preferences ($p(s)$) over sensory states (e.g., "battery level > 20%"), the agent is structurally bound to satisfy them. It cannot "misinterpret" the goal because the goal is defined as the physiological state it must inhabit to minimize Free Energy.

### 5. Implementation Roadmap: Hardware and Software Integration
The realization of this architecture requires a shift from standard von Neumann computing (CPU/GPU) to Neuromorphic Hardware, which naturally supports the sparse, asynchronous, and event-driven nature of the specified algorithms.

#### 5.1 Neuromorphic Hardware Specification (Loihi 2 / SpiNNaker 2)
*   **Processor:** We specify Intel Loihi 2 or SpiNNaker 2 as the target hardware.
*   **Neuron Model:** Leaky Integrate-and-Fire (LIF) neurons with adaptive thresholds are used to implement the Predictive Coding error units. The spiking nature captures the precise timing required for Spike-Timing-Dependent Plasticity (STDP).
*   **Communication:** Address Event Representation (AER) is used for inter-module communication. Thalamic Gating is implemented by dynamically enabling/disabling routing table entries in the SpiNNaker interconnect fabric, physically stopping the packet flow.

#### 5.2 Local Learning Rules: Eliminating Backpropagation
Global backpropagation is computationally expensive and biologically impossible. We specify Local Learning Rules enabled by the neuromorphic cores.

**Specification:**
*   **Three-Factor Hebbian Learning:** Synaptic updates $\Delta w_{ij}$ depend only on:
    *   Presynaptic trace ($x_j$).
    *   Postsynaptic trace ($y_i$).
    *   Global Modulatory Signal ($M$, e.g., Dopamine/Reward or Norepinephrine/Surprise).
    $$\Delta w_{ij} = \eta \cdot M \cdot (x_j \cdot y_i - \text{decay})$$
*   **NoProp / Forward-Forward:** For deep hierarchical learning, we utilize the Forward-Forward algorithm or NoProp, which trains layers locally to distinguish "positive" (real) data from "negative" (hallucinated) data. This allows each layer to update independently without waiting for a global error signal, enabling massive parallelism.

### 6. Conclusion
This report transforms the high-level "blueprint" into a rigorous Engineering Specification. We have replaced abstract boxes with concrete dynamical systems:
*   **Algorithmic execution** is defined as energy minimization in Modern Hopfield Networks and Constraint Satisfaction Networks.
*   **Coordination** is guaranteed by Vector Symbolic Architectures and Thalamic Gating.
*   **System 2** is stabilized by Neural Algorithmic Reasoning and Value of Information stopping criteria.
*   **Embodiment** is enforced by the Active Inference loop, using prediction error to ground symbols in reality.

By building on these specifications, utilizing local learning rules, and deploying on neuromorphic hardware, we move from simulating cognition to instantiating it. This architecture is not just a model of a mind; it is a blueprint for a synthetic organism capable of robust, adaptive survival in the real world.
