## 🎯 Quick Reference

### Key Metrics
- **System Size:** ~50 MB RAM
- **Inference Speed:** 3-5 ms per decision
- **Energy:** 0.003 mJ per inference (1000× less than GPT-2)
- **Parameters:** ~1M (vs billions in LLMs)
- **Learning Time:** 100 episodes (~2 minutes)

### Supported Platforms
- ✅ Windows 10/11
- ✅ Linux (Ubuntu, Debian, etc.)
- ✅ macOS 12+
- ✅ Raspberry Pi 4/5
- ✅ Android 10+
- ✅ Cloud (Docker/K8s)
- ✅ Neuromorphic (Intel Loihi)
