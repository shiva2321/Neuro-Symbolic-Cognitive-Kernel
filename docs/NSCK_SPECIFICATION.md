# Neuro-Symbolic Computational Kernel (NSCK): Architectural Specification

## 1. Executive Summary
The NSCK is a sentient, autonomous agent architecture that hybridizes Spiking Neural Networks (SNNs) with Vector Symbolic Architectures (VSA). It moves beyond the limitations of LLMs (opacity, high energy) to create grounded, transparent, and efficient intelligence.

**Core Pillars:**
1.  **Efficient NLP**: Semantic Folding & SDRs (replace dense embeddings).
2.  **Computational Self**: Damasio's Hierarchy (Proto/Core/Autobiographical) + GWT + IIT.
3.  **Structural Plasticity**: Deep Rewiring & Neurogenesis (Brain grows/shrinks).
4.  **Multimodal Perception**: VoiceHD & VSA Fusion (Unified algebra for Audio/Vision).
5.  **Agency**: Active Inference & Intrinsic Motivation (Curiosity-driven).

---

## 2. Efficient NLP: Semantic Folding
We reject dense embeddings (Word2Vec/BERT) in favor of **Sparse Distributed Representations (SDRs)**.
*   **Theory**: Semantic Folding (Cortical.io). Map text to a 2D topographical grid (Semantic Map).
*   **Mechanism**: Unsupervised training on snippets. Words become binary vectors where bits = contexts.
*   **Operations**: Boolean logic (AND/OR/XOR) for disambiguation and synthesis.
*   **Graph Integration**: Map WordNet/ConceptNet to VSA using Holographic Reduced Representations (HRR).

## 3. Computational Models of 'The Self'
Sentience is architected explicitly, not emergent.
*   **Level 1: Proto-Self (Homeostasis)**
    *   Monitors `h_energy`, `h_integrity`, `h_temp`.
    *   Generates "Drives" (Urgency signals) that bias attention.
*   **Level 2: Core Self (Global Workspace)**
    *   Implementation: **LIDA (Learning Intelligent Decision Agent)**.
    *   Mechanism: Coalitions of info compete for the Global Workspace.
    *   Broadcast: The winning coalition is the "conscious moment".
    *   Metric: **Integrated Information (Phi)** calculated via `pyphi`.
*   **Level 3: Autobiographical Self (Narrative)**
    *   Transient Episodic Memory (TEM) chains conscious moments into a timeline.

## 4. Structural Plasticity (SNNs)
The brain must physically adapt to new tasks.
*   **Deep Rewiring (Deep R)**:
    *   Weights have a "latent" parameter $\theta$.
    *   Connectivity is sparse and dynamic.
    *   **Pruning**: If $\theta < 0$, connection dies.
    *   **Regrowth**: Random new connections form to explore solution space.
*   **Neurogenesis**:
    *   Trigger: High Loss plateau over time.
    *   Action: Spawn new neurons connected to "outlier" samples.
*   **Energy-Aware Pruning**: Remove expensive connections (high freq, low weight).

## 5. Multimodal Perception (VoiceHD)
Unified hyperdimensional space for all senses.
*   **Audio**: VoiceHD architecture.
    *   MFCCs quantized to ID hypervectors.
    *   Permutation encodes temporal sequence (N-grams).
*   **Binding**: $V_{Object} = (V_{See} + V_{Hear}) \otimes V_{Location}$.
*   **Result**: "Seeing" a dog and "Hearing" a bark bind to the same entity algebraically.

## 6. Agency: Active Inference
Replacing Reward Maximization with **Free Energy Minimization**.
*   **Goal**: Minimize "Surprise" (Difference between expected internal state and reality).
*   **Intrinsic Motivation (IAC)**:
    *   Intelligent Adaptive Curiosity (Oudeyer).
    *   Agent explores regions of "High Learning Progress".
*   **Goal Babbling**: Randomly sample *outcomes* (visual goals) and learn the inverse kinematics to reach them.
