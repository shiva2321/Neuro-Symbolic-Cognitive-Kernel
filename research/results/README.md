# Research Results

This directory contains JSON result files generated by running the experiment scripts in `research/experiments/`.

## Generating Results

From the repository root:
```bash
cd nsck
python ../research/experiments/run_all_experiments.py
```

Or run individual scripts:
```bash
cd nsck
python ../research/experiments/paper4_snn_benchmarks.py
python ../research/experiments/paper5_transplant_benchmarks.py
python ../research/experiments/paper6_active_inference_benchmarks.py
python ../research/experiments/paper7_memory_benchmarks.py
python ../research/experiments/paper8_safety_benchmarks.py
```

## Output Files

| File | Paper | Description |
|------|-------|-------------|
| `paper4_results.json` | Paper 4 | SNN perception benchmarks |
| `paper5_results.json` | Paper 5 | Model transplantation benchmarks |
| `paper6_results.json` | Paper 6 | Active inference + GWT benchmarks |
| `paper7_results.json` | Paper 7 | Homeostatic memory benchmarks |
| `paper8_results.json` | Paper 8 | Safety + emotion benchmarks |

## Notes

- JSON files are machine-generated and should not be manually edited.
- Results depend on hardware; numbers will vary across machines.
- The experiment scripts use the Python backend by default; if Rust extensions are built, they will be used automatically.
- Re-running an experiment overwrites its JSON file.
